# Meenakshi S | Portfolio

A personal portfolio website designed to showcase my skills, experience, projects, and contact information in a clean and professional format.

## Overview

This portfolio is built using plain HTML, CSS, and JavaScript, making it lightweight, easy to customize, and simple to deploy.

## Features

- Responsive personal portfolio layout
- About section
- Skills and expertise highlights
- Project showcase
- Experience / resume details
- Contact section
- Clean and modern design

## Project Structure

- `Meenakshi S · Portfolio.html` — Main portfolio page
- `README.md` — Project documentation

## How to View Locally

Open the HTML file in your browser:

```bash
start "Meenakshi S · Portfolio.html"
```

Or simply double-click the file in File Explorer.

## Deployment

This site can be hosted on GitHub Pages or any static hosting platform.

### GitHub Pages

1. Push the project to GitHub
2. Open the repository settings
3. Go to Pages
4. Select the main branch as the source
5. Save and publish

## Customization

You can easily update:
- your name and title
- profile summary
- work experience
- projects
- social links
- contact details
